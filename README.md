# Yoichi Tsuchiya — Academic Website

Academic website of Yoichi Tsuchiya, Professor, School of Commerce, Meiji University.

The site is bilingual (English/Japanese) and is maintained with Quarto. The rendered site is published from `docs/` via GitHub Pages.

## Structure

- `index.qmd`, `research.qmd`, `publications.qmd`, `cv.qmd`, `contact.qmd` — English source pages
- `jp/` — Japanese source pages
- `assets/` — CV PDFs
- `styles.css` — shared styling
- `docs/` — rendered website for GitHub Pages

## Publishing

GitHub Pages should be configured to deploy from the `main` branch and `/docs` folder.
